Read [README.md](README.md) for this repository's purpose and release rules.

## Shared company policies

- Record who is working where with [uptomic-work-record](.agents/skills/uptomic-work-record/SKILL.md).
  This repository has no Beads: put the same record fields (agent tool, model, session, operator,
  host, repository, worktree, branch, head) in the task's tracker entry at claim and handoff.
- An owner-marked urgent change may use the
  [expedited release lane](.agents/skills/uptomic-expedited-release/SKILL.md). It adds to, and
  never replaces, this repository's release rules, promotion gates and production holds.
